# Spike Radar

Flags Edgenuity progress that looks too fast, so a person can take a look.

**Live demo:** https://jharvey1113.github.io/spike-radar-demo/ (600 made-up students, 12 days of reports)

## How it works

1. Save each day's Edgenuity **Manage Enrollments** report into one folder. Keep the date in the filename.
2. Open the page, click **Load different reports**, and select all of the saved reports.
3. Work the review queue: mark each flagged student **Concern** or **Looks fine**.

Each student is compared to their own normal pace and to how much active time they logged.
No AI is involved: every flag comes from simple rules and says why in plain words.

## Privacy

The page is a single HTML file with no outside connections. Reports are read in your browser
and never uploaded anywhere. To work with real student reports, save `index.html` to your own
computer and open it from there.
